# ⚡ Daily Habit Tracker

A clean and simple web application to track daily study routines, screen-time control, and productivity.

🔗 **Live Demo:** https://rubaiya17.github.io/Daily-Habit-Tracker/

---

## 🎯 3 Core Habits Tracked
1. 📚 **Maintained a Fixed Study Routine**
2. 📵 **Avoided Unnecessary Phone Use**
3. 🎯 **Completed Today's To-Do List**

---

## ✨ Features
- **Daily Habit Grid:** Easily mark habits as Done (✓) or Missed (✕).
- **Monthly Summary:** Real-time completion rate, streak count, and progress bar.
- **Progress Calculator:** Calculate scores and ratings for 3 days, 5 days, 7 days, or the whole month.
- **Activity Chart:** Live trend graph powered by Chart.js.
- **Dark Mode:** Quick toggle between light and dark themes.
- **Export Data:** Download monthly records as an Excel CSV file.
- **Auto-Save:** All progress stays saved in the browser via LocalStorage.

---

## 🛠️ Built With
- HTML5
- Tailwind CSS / CSS3
- JavaScript (Vanilla ES6)
- Chart.js
